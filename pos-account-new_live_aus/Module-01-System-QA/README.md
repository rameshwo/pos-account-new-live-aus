Module-01-System-QA

This module provides a PowerShell-based system QA scaffold to validate developer environments for Flutter/Dart development.

Usage:
- Open a PowerShell terminal in this folder and run `.\
unsystem-qa.ps1` (or `Run-System-QA.ps1`).
- Individual checks live in the `checks/` folder.
- Reports are generated into the `reports/` folder.
